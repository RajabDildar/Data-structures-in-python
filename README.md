# Data Structures in Python

A practical Python repository focused on learning and implementing common data structures and algorithms through interactive Jupyter notebooks and Python examples.

This project is designed for students, beginners, and anyone who wants to understand how fundamental data structures work in Python through visual, step-by-step examples and code snippets.

## Overview

The repository contains implementations and explanations for several core computer science topics, including:

- Arrays and dynamic lists
- Linked Lists
- Stacks
- Queues
- Trees and Binary Search Trees
- Hashing and Dictionaries
- Searching algorithms
- Sorting algorithms
- Graph representations and traversal concepts
- Recursion

## Repository Contents

| File / Notebook | Topic |
| --- | --- |
| `List.py` | Custom dynamic list implementation in Python |
| `index.ipynb` | Entry notebook / quick reference |
| `LL.ipynb` | Linked List concepts and implementation |
| `stacks-LL.ipynb` | Stack using linked list |
| `Queue-LL.ipynb` | Queue using linked list |
| `BST.ipynb` | Binary Search Tree |
| `Trees-LL.ipynb` | Tree structures and linked representation |
| `Dictionary-hashing.ipynb` | Dictionary and hashing basics |
| `Hashing-using-chaining.ipynb` | Hashing with chaining collision handling |
| `Searching.ipynb` | Linear and binary search techniques |
| `Sorting.ipynb` | Sorting algorithms and examples |
| `Recursion.ipynb` | Recursive functions and problem-solving patterns |
| `graph.ipynb` | Graph fundamentals |
| `graph-with-list.ipynb` | Graph representation using adjacency lists |

## What You Will Learn

- How different data structures store and organize data
- Time and space trade-offs of common structures
- How algorithms operate on data efficiently
- How to implement core concepts in Python from scratch
- How to explore data structures interactively using notebooks

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/RajabDildar/Data-structures-in-python.git
cd Data-structures-in-python
```

### 2. Install Jupyter

```bash
pip install notebook jupyterlab
```

### 3. Launch the notebooks

```bash
jupyter notebook
```

Then open any `.ipynb` file to explore the examples.

### 4. Run the Python implementation file

```bash
python List.py
```
